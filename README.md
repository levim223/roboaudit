# RoboAudit 🤖🔍
### Open-Source Robotics Episode Quality & Invariant Auditing Engine

RoboAudit is an open-source, format-agnostic data quality and annotation auditing pipeline for robot learning demonstrations and teleoperated episodes. It audits robot demonstration episodes, validates EARS specifications, detects operator mistakes (drops, fumbles, idle pauses), and verifies physical invariants (progress monotonicity, timebase jitter, sensor-camera synchronization) using Custom Agents, Powers, and Model Context Protocol (MCP) tools.
